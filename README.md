JLauncher is a desktop companion for Horizon, the Rust-based Minecraft: Java Edition client. It brings account sign-in, game setup, instance management, and supported mod features into one interface.

## Features

- **Guided first-run tutorial:** Helps you through initial setup and connecting your account.
- **Microsoft account sign-in:** Connect the account that owns Minecraft: Java Edition.
- **Horizon setup:** Helps install Horizon when a compatible official macOS package is available.
- **Update checks:** Checks for newer JLauncher releases when the application starts.
- **Instance management:** Keep separate Minecraft configurations and choose which one to launch.
- **Game version selection:** Select from versions made available by Horizon.
- **Compatible mod browser:** Browse and install mods supported by Horizon.
- **Modpack importing:** Import supported modpack archives, including compatible `.mrpack` files.
- **Troubleshooting information:** Use available logs and diagnostics to investigate problems.

## Compatibility notes

- A Microsoft account that owns Minecraft: Java Edition is required to play.
- Horizon must provide a compatible macOS launcher package for installation and gameplay to work.
- The macOS application is currently unsigned and not notarized. macOS may ask you to approve the app in Privacy & Security before opening it.
- Mod compatibility depends on Horizon. Arbitrary Java mod JAR files are not guaranteed to work.

## Getting started

Open JLauncher and follow the setup tutorial. Connect your Microsoft account, complete the Horizon setup when supported, and select or create an instance before launching.

## Troubleshooting

If the application is blocked by macOS, review the approval options in System Settings under Privacy & Security. If Horizon cannot be installed or launched, check whether an official macOS-compatible Horizon package is available.
