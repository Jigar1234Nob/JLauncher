# Jigarzon Launcher

Jigarzon Launcher is a simple Windows desktop launcher for Horizon, the Rust-based Minecraft: Java Edition client.

## Features

- Guided first-time setup: Microsoft sign-in, latest Horizon Nightly installation, then Minecraft game-file preparation.
- Prism-inspired dark interface with consistent colours, borders and rounded controls.
- Home dashboard with a single Play button, selected-instance switcher and Horizon release news.
- Instance manager to create, select, rename, reinstall and delete instances.
- Mod browser to search for and install Horizon-compatible mods into the selected instance.
- Settings to check, download and repair Minecraft game files, and update Horizon.

A Microsoft account that owns Minecraft: Java Edition is required. Microsoft sign-in is handled by Horizon using Microsoft's device sign-in flow. Minecraft assets are downloaded from Mojang through Horizon and are not bundled with Jigarzon.

Jigarzon is an independent project and is not affiliated with Mojang Studios or Microsoft.
